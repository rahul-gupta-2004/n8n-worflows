
# n8n Workflows

A collection of self-hosted n8n automation workflows.

## Workflows

* [Local AI RSS-to-Telegram News Brief](./rss-telegram-brief/) - Aggregates tech RSS feeds, summarizes them using a local Ollama LLM, and sends a clean digest to Telegram.

## Requirements

* n8n (Docker)
* Ollama (local LLM instance)
